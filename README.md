# horizon-kiln-site

The website for [Kiln](https://github.com/Manager1215/horizon-kiln), live at [horizon-kiln.cc](https://horizon-kiln.cc).

Plain HTML, CSS and a little JavaScript, no build step for the pages themselves. The mod catalogue (`mods.json`, `mods/`, `stats.json`) is generated by `.github/scripts/` from Kiln's catalogue branches and committed by CI.

`server/kiln-accounts.py` is the accounts and reports service behind `/account/` and `/reports/`. Python standard library only, SQLite for storage.

## Preview

```sh
python3 -m http.server 8000
```

The account pages need the service running, everything else works as static files.

## Hosting

Server setup lives in [Manager1215/infra](https://github.com/Manager1215/infra), role `kiln_site`: nginx, the systemd unit for the accounts service, rate limits and the deploy user. This repo only holds the site.

CI uploads with rsync over SSH as a user that can only write the web root. Secrets: `DEPLOY_HOST`, `DEPLOY_SSH_KEY`, `DEPLOY_KNOWN_HOSTS`.
