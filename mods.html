Supported mods

Java (Fabric) mods and what Kiln can do with each one today. Each entry says exactly how far it has been checked, nothing more; the list grows with each Kiln release.

Status

What the statuses mean
Works
Tried in the game with Kiln. The entry says what works.
next: Works
A second, quieter mark: what the current development build does when it differs from the release. The switch above counts that build instead; see the FAQ.
Should work
An automatic test ran the mod on Kiln’s test stand (its own code, with a scripted minute of play in place of the game) and nothing broke, and everything it called is written in Kiln: it most likely works. Nobody has checked it in the game by hand yet; that is “Works”.
Planned
Calls something that is on Kiln's roadmap. Parts of it may already run.
No plans yet
Calls something that is not on Kiln's roadmap yet. Parts of it may already run.
Not checked
In the catalogue, not checked yet.
Doesn't work
Tried in the game with Kiln; it does not work yet.
In development
Kiln is being built with this mod. Not released.
