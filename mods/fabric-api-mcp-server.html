In the author's words

A Model Context Protocol (MCP) server that runs inside Minecraft Java Edition as a Fabric mod. It exposes the server-side Minecraft API and the Fabric API as MCP tools so Claude, Cursor, etc. can read and manipulate a live world programmatically.
